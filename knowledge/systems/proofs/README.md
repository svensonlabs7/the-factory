# Proofs

The experiment behind each `proven` card, named `<NNN>_<slug>.py` (or a `<NNN>/` folder). Run from the repo root,
for example `python3 knowledge/systems/proofs/011_timeouts.py`. Scripts that import `test_adapter` need
`PYTHONPATH=tests`. Some probe live systems read-only (Docker, `gh`, `dig`); the rest are self-contained models.
